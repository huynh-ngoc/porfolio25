# Ngoc Huynh – Portfolio 💻

Welcome to my personal portfolio website, built with **Next.js**, **Tailwind CSS**, and hosted on **Vercel**. This site showcases my software engineering experience, personal projects, and contact information.

## 🚀 Live Site

[https://ngochuynh-portfolio.vercel.app/]

## 🛠 Tech Stack

- **Frontend**: React, Next.js, Tailwind CSS
- **Backend**: Node.js, Express
- **Mobile**: Flutter
- **Database**: MongoDB, PostgreSQL, Cassandra
- **Other**: Firebase, AWS, Google Cloud, Streamlit, GitHub

## 📁 Features

- Smooth scroll + animations with AOS
- Light/dark mode toggle
- Filterable tech stack
- Responsive layout (mobile-first)
- Project highlights with tech tags
- Contact form + social links
